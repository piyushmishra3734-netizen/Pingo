# Sign-in art

`paint.webp`, `friends.webp`, `clouds.webp` and `clouds-dark.webp` are generated by
`apps/web/scripts/make-auth-art.cjs` (domain-warped noise, signed-distance figures,
a Kuwahara pass for the brush marks). Nothing here is drawn from or licensed from
anyone else. Re-run with `node scripts/make-auth-art.cjs public/auth` (needs `sharp`
resolvable, e.g. via NODE_PATH). Used by `src/features/auth/AuraShell.tsx`.
